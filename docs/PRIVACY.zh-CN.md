# 隐私与数据说明

本说明对应 Windows **0.4.83** 的当前实现。Android 是独立产品，请以其商店页面及隐私说明为准。

## 你自己的 API Key

Windows 版本不提供开发者的 API Key，也没有共享的免费调用额度。首次使用时，请在设置中选择 Gemini 或 OpenAI，填写你自己的 Key。语音输入、翻译输入、Notes 和实时语音聊天会使用当前选择的供应商与 Key。调用费用、额度、可用模型和地区限制由相应供应商决定。

Key 在本机使用 Windows DPAPI 的 `CurrentUser` 范围加密，保存在 `%APPDATA%\VoiceTypingAI\settings.ini`。加密内容与当前 Windows 用户环境关联，不能把这个文件当作通用配置分发。DPAPI 也不代表能防御已控制当前用户会话的程序；请保护自己的 Windows 账号。

## 哪些数据会发往云端

本程序通过网络调用所选供应商。录音或语音流、待处理文本、翻译内容，以及使用功能所需的对话上下文可能发往 Gemini 或 OpenAI。实时聊天涉及本地日程、备忘时，相关内容可能进入对话上下文。开启 Gemini 聊天的联网搜索后，也会使用供应商的联网能力；该开关默认关闭。

“本地 VAD”表示在本机检测语音活动，**不表示离线识别**。服务端的保留、使用和计费规则，请查看你所用供应商及账号的最新条款。本仓库不承诺供应商零保留，也没有验证所有账号和地区都可用。

## 本机可能保留什么

| 内容 | 位置与行为 |
| --- | --- |
| 设置与加密 Key | `%APPDATA%\VoiceTypingAI\settings.ini` |
| 便签、日程与聊天历史 | 同目录中的 `widgets.json`、`schedules.json`、`realtime-conversations.json` 等文件，可能存在 `.bak` 备份 |
| 运行日志 | 同目录中的 `debug.log`、`debug.log.1` 等，可能包含识别文字、上下文或故障信息 |
| 处理后的输入录音 | 当前版本会自动写入应用选择的数据目录下的 `processed-audio`；从源码目录运行时也可能落在项目目录 |
| 临时录音 | Windows 临时目录中的音频文件，包括 `voice-typing-ai-last-recording.wav` |

便携版仍会写入用户配置目录，并非“退出后不留数据”。当前版本没有关闭录音归档的设置；移除程序也不等于已清除上述数据。便签、日程、聊天和音频并未因为 API Key 使用 DPAPI 而一并加密。

## 分享问题报告之前

不要上传 `settings.ini`、完整用户数据目录、录音、聊天历史、未检查的日志，或含 Key 的设置截图。描述问题时优先提供版本号、所用供应商、操作步骤和已脱敏的错误摘要。

源码中的字段名、空的 Key 默认值和测试用假值不是可用凭据。请勿把自己的真实 Key 写进源码、测试夹具、构建脚本、提交记录或 Issue。

## 清理自己的本地数据

先退出程序，再按需检查上述位置；只删除确认属于本应用、且自己不再需要的文件。清理聊天时还要检查备份，清理录音时还要检查临时文件。删除配置后需要重新填写自己的 Key。若 Key 曾公开泄露，应在对应供应商后台撤销或轮换；仅删除本地文件或 GitHub 文件不能撤回已泄露的凭据。

## 公开仓库的范围

公开仓库仅包含 Windows 构建所需源码、构建脚本、离线测试和公开说明素材。发布时从明确的文件清单复制，不包含开发者的运行配置、历史录音、个人日志、内部交接材料或旧版本备份。`tests/fixtures/android829-input.json` 是 Windows 的输入协议回归测试夹具，不是 Android 应用源码。

安装包与便携程序作为对应版本的 GitHub Release 附件提供，附有 SHA-256 校验值。隐私检查可以降低泄露风险，不能代替对程序全部安全性的审计。
